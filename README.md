## 📌 Про проєкт

**Trevoga** — Telegram-бот на [Telethon](https://docs.telethon.dev/), який слухає канали-джерела, пересилає новини до службової групи модерації, а після схвалення (вручну або через AI) публікує їх у цільові групи та канали. Підтримує AI-редактуру тексту, водяні знаки, статистику, підписки на ключові слова та карту повітряних тривог.

Проєкт складається з **двох процесів**, які ділять одну базу `trevoga.db`:

1. **Юзербот** (`main.py`, Telethon) — слухає джерела, публікує пости, виконує адмін-команди.
2. **Бот-підписник** (`botsrc`, aiogram) — приймає `/sub` та `/unsub` у приватних повідомленнях і розсилає сповіщення за ключовими словами **від свого імені** (акаунт юзербота в розсилці не задіяний — це захищає його від бану за автоматизацію).

## ✨ Можливості

| | Функція | Опис |
|---|---|---|
| 📥 | **Пересилання постів** | Слухає `SOURCE_CHANNELS` → службова група `GROUP_C` → цільові `GROUP_D_TARGETS` / `CHANNEL_TARGETS` |
| 🤖 | **AI-модерація** (`.ai`) | Перевірка корисності новини через OpenAI-сумісний API, авто-схвалення/відхилення |
| ✍️ | **AI-редактура** (`.fix`) | Переписування тексту: стилі `short`, `urgent`, `official`, `neutral`, режим `test`, `undo` та власна інструкція |
| ✅ | **Авто-редактура** (`.aicheck`) | Автоматичне переписування опублікованих постів у «official»-стилі |
| 🛡️ | **Модерація каналів** | Перезаливка постів адмінів з водяним знаком OpenTrevoga, видалення оригіналів |
| 🚫 | **Виключення каналів** (`.cignore`) | Канали, що не підлягають модерації |
| ➕ | **Керування джерелами** (`.addchannel`) | Додавання/видалення/список каналів-джерел на льоту |
| 💧 | **Водяний знак** (`.wmark`) | Увімк/вимк посилання в підписі постів |
| 🖼️ | **Фото-картки** (`.cart`) | Увімк/вимк фото-картки для постів |
| 📊 | **Статистика** (`.stats`) | Звіт щодо публікацій за період або загалом |
| 🗺️ | **Карта тривог** (`.map`) | Скріншот офіційної карти повітряних тривог України (JPEG) |
| 🩺 | **Стан бота** (`.health`) | Uptime, доступність AI, розмір БД, FloodWait, остання помилка |
| 🔔 | **Підписки** (`/sub` / `/unsub`) | Сповіщення за ключовими словами (окремий бот `botsrc`) |
| 💾 | **Сховище** | SQLite (`trevoga.db`): пости, статистика, модерація, підписки |

## 🧱 Стек

- **Python 3.11**
- [**Telethon**](https://docs.telethon.dev/) — MTProto клієнт Telegram (юзербот)
- [**aiogram**](https://docs.aiogram.dev/) — Telegram Bot API (бот-підписник)
- **SQLite** — локальне сховище
- **httpx** — HTTP-клієнт для AI API
- [**Playwright**](https://playwright.dev/python/) — рендер карти тривог (headful Chromium)
- **Pillow** — конвертація PNG → JPEG для надсилання фото
- **pytest** / **ruff** — тестування та лінтинг

## ⚙️ Встановлення

```bash

```

## 🔧 Налаштування

Скопіюйте `.env.example` у `.env` та заповніть значення:

```bash
copy .env.example .env
```

## 🚀 Запуск

### 1. Юзербот (Telethon)

```bash
python main.py
```

Слухає канали-джерела, публікує пости в `GROUP_C`, виконує адмін-команди.

При першому запуску Telethon запросить авторизацію (номер телефону / код), після чого створить файл сесії.

### 2. Бот-підписник (aiogram)

```bash
python -m botsrc
```

Бот приймає `/sub` / `/unsub` у **особистих повідомленнях** та розсилає сповіщення за ключовими словами **від свого імені**.

> ⚠️ Бота треба додати **адміністратором** у канал `GROUP_C`, інакше він не бачитиме нових постів каналу.
> У `.env` мають бути заповнені `BOT_TOKEN` і `GROUP_C`.

## 🛠️ Команди адміністратора

> Виконуються **юзерботом** у службовій групі `GROUP_C` (окрім `.map` і `.help`)

| Команда | Дія |
|---|---|
| `.ai` / `.ai on` / `.ai off` / `.ai status` | Керування AI-модерацією |
| `.ai set [MODEL] [fix]` | Зміна моделі AI (з `fix` — для `.fix`); без аргументу — список доступних моделей |
| `.aicheck` / `.aicheck on` / `.aicheck off` | Авто-редактура опублікованих постів |
| `.fix` (відповіддю) | AI-редактура тексту поста |
| `.fix [short\|urgent\|official\|neutral]` | Редактура в заданому стилі |
| `.fix test [режим] [прохання]` | Показати результат, не змінюючи пост |
| `.fix [прохання]` | Власна інструкція редактору (напр. «прибери мат») |
| `.fix undo` | Повернути початковий текст (протягом 10 хвилин) |
| `.fix help` | Довідка щодо `.fix` |
| `.wmark` / `.wmark on` / `.wmark off` | Водяний знак у підписі |
| `.cart` / `.cart on` / `.cart off` | Фото-картки для постів |
| `.cignore [ID/@name]` / `.cignore off` / `.cignore list` | Виключення каналів з модерації |
| `.addchannel add\|del\|list [ID/@name]` | Керування каналами-джерелами |
| `.stats` / `.stats 12` / `.stats 24` | Статистика публікацій за період або загалом |
| `.health` | Стан бота (uptime, AI, БД, FloodWait, остання помилка) |
| `.ai_reason [MESSAGE_ID]` | Причина рішення AI щодо поста (або відповіддю на повідомлення) |
| `.map` | Карта повітряних тривог України (JPEG) — працює в будь-якому чаті |
| `.відміна` / `.delete` / `.видалити` | Скасування/видалення поста |
| `.help` | Список команд (адмінський або користувацький залежно від прав) |

## 🔔 Команди бота-підписника

Приймаються **ботом-підписником** у приватних повідомленнях (`python -m botsrc`).
Юзербот команди підписки **не обробляє** — це захищає акаунт від бану за автоматизацію.

| Команда | Дія |
|---|---|
| `/sub [СЛОВО]` | Підписатися на ключове слово |
| `/sub` | Показати мої підписки |
| `/unsub [СЛОВО]` | Відписатися від ключового слова |
| `/unsub all` | Скинути всі підписки |
| `/settings` | Налаштування підказок (📷 фото-картки, 🔗 посилання на Вікіпедію) |
| `/users` | Статистика користувачів (лише для адміністратора) |
| `/map` | Карта повітряних тривог України (JPEG) |
| `/start` / `/help` | Головне меню та довідка |
